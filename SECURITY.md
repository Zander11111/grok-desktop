# Security policy

Grok Desktop can run shell commands and control the mouse and keyboard on behalf of the model, so security reports are very welcome.

Please **do not open a public issue** for vulnerabilities. Report them privately via GitHub:
**Security** tab → **Report a vulnerability** ([link](https://github.com/Zander11111/grok-desktop/security/advisories/new)).

Only the latest release is supported with fixes.
