# Contributing

Thanks for helping out!

- Open an issue first for anything bigger than a small fix, so we can agree on the approach.
- Run the tests before opening a pull request: `scripts/run-tests.sh` (they use a fake `grok`, no network or account needed).
- Keep pull requests focused; describe what changed and how you tested it.
- Never commit API keys, tokens, voice model files or build output (`dist/`, `.venv/`).
